    How it works

    From sound to study notes,
    without lifting a pen.

    01

    Press record. Play anything.

    YouTube, Coursera, a Zoom recording, a podcast. Scribely hears your computer's sound, never your microphone. Pause when you pause the video; the timestamps stay in sync.

    02

    Watch the transcript write itself.

    Whisper runs locally and turns speech into timestamped text within a second or two, in any of 100 languages. Nothing is uploaded, nothing is billed per minute.

    03

    Stop, then ✦ Summarize.

    When you're done, the AI model you chose writes structured notes with a summary and sections that link back to the moment they were said. Hours-long lectures are split and merged so nothing is cut off.

    04

    Make them yours.

    Restructure into a study outline, Q&A or a condensed version. Edit anything by hand. Search every session you've ever recorded. Export a beautiful PDF or a web page.

    Get started

    Up and running in four commands.

    Scribely runs from source today. You'll need Git, uv, Node 22, pnpm and Rust; the guides walk you through installing them.

    # one-time: brew install git uv node@22 pango && npm i -g pnpm@10 (+ Rust)
$ git clone https://github.com/arkapatra31/Scribely.git && cd Scribely
$ cd backend && uv sync && cd ..
$ pnpm install
$ pnpm dev
